rs-threadpool-webserver

A multi-threaded TCP web server written in pure Rust (no web frameworks).

What you get

  • Custom fixed-size thread pool (Arc + Mutex + mpsc)
  • HTTP/1.1 request parsing and responses
  • Static file serving with path-traversal protection
  • Graceful 404 / 400 handling without panics

Try it

  • /about
  • /missing-page (triggers 404)
  • /style.css
Built with std::net, std::thread, and std::sync.
